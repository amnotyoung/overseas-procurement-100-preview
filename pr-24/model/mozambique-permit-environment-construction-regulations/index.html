국가별 건축 인허가 절차 · 14단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · 모든 개발사업은 환경 사전평가로 A+, A, B 또는 C를 분류받는다. A+/A는 전면 환경영향평가(EIA), B는 간이환경조사(simplified environmental study), C는 승인받은 우수관행 지침(good-practice instrument) 경로이며 환경허가 뒤 관할 지방자치단체·지구행정청(municipality/district)이 건축허가를 결정한다.

  1. B01 환경 사전평가서류 제출 — 사업설명·입지·토지사용수익권(DUAT)·예상 생물물리·사회영향과 법정 첨부자료를 환경기관에 제출해 환경영향평가 절차(AIA)를 개시한다. / 산출물: 절차개시 접수(Instrução do processo)·사전평가 기록
  2. B02 A+·A·B·C 공식분류 — 관할 환경기관이 사업의 성격·규모·입지·민감도와 잠재영향을 심사해 A+, A, B 또는 C로 분류하고 필요한 평가도서·심사기관을 통지한다. / 산출물: 환경 카테고리·평가경로 공식통지
  3. B03 A+/A 환경사전타당성·범위설정서(EPDA)·과업지시서 또는 B 과업지시서 작성 — A+/A는 환경사전타당성·범위설정서와 환경영향평가 과업지시서를, B는 간이환경평가 과업지시서를 작성해 환경기관 승인을 요청한다. / 산출물: 환경사전타당성·범위설정서·과업지시서 또는 B등급 과업지시서
  4. B04 C등급 우수환경관리관행절차(PBPGA) 작성 — C 사업은 예상영향의 관리조치를 담은 환경우수관행 절차·지침을 작성해 공식승인(homologation)과 환경허가를 요청한다. / 산출물: 우수환경관리관행절차·우수관행 지침
  5. B05 과업지시서 승인·A+ 독립검토자 지정 — 환경기관이 환경사전타당성·범위설정서와 과업지시서를 심사·승인하고 A+ 사업에는 공인 독립전문가의 동료검토(peer review)·감독을 적용한다. / 산출물: 승인 범위설정서·과업지시서·A+ 독립검토 계획
  6. B06 법정 공중참여 실시 — A+/A는 최소 2회, B는 최소 1회의 참여협의(participatory consultation)를 실시해 이해관계자 의견과 반영결과를 평가도서에 포함한다. / 산출물: 공중참여 공고·회의록·의견반영표
  7. B07 환경영향평가·간이환경평가(EAS)·우수환경관리관행절차 최종제출 — 승인 과업지시서와 공중참여 결과에 따라 A+/A 전면 환경영향평가, B 간이환경평가 또는 C 우수환경관리관행절차를 완성해 제출한다. / 산출물: 환경영향평가·간이환경평가 또는 우수환경관리관행절차 최종본
  8. B08 환경기술위원회·독립검토 심사 — 환경기관의 기술평가위원회가 평가서·관리계획·공중의견을 심사하고 A+는 독립전문가 검토를 포함해 승인권고·보완 또는 거부안을 작성한다. / 산출물: 기술심사의견·독립검토·보완요구
  9. B09 환경평가서·관리계획 보완 — 기술위원회 또는 독립검토자의 추가조사·대안·저감·공중의견 반영 요구를 수정 평가서와 관리계획에 반영해 재제출한다. / 산출물: 보완 환경영향평가·간이환경평가·우수환경관리관행절차·답변서
  10. B10 환경허가 공식결정 — 관할 환경기관이 분류별 평가도서와 심사결과를 토대로 설치단계 환경허가(Licença Ambiental de Instalação)를 발급하거나 조건·보완·거부를 공식 통지한다. / 산출물: 설치 환경허가·조건 또는 거부통지
  11. B11 환경허가 포함 건축허가 신청 — 환경허가와 토지사용수익권·건축프로젝트·설계자 책임서·보완설계를 관할 지방자치단체·지구행정청에 제출해 건축허가를 신청한다. / 산출물: 완비 건축허가 신청
  12. B12 건축·보완설계 기술심사 — 기술부서가 환경조건, 승인 건축프로젝트와 구조·상하수·설비 보완설계의 일치·안전성을 심사하고 보완 필요사항을 통지한다. / 산출물: 건축기술 심사의견·보완요구
  13. B13 건축허가도서 보완·재심 — 환경허가조건과 기술심사 지적을 반영해 건축·구조·설비도서를 수정하고 관할기관에 재제출한다. / 산출물: 수정 허가도서·보완답변
  14. B14 건축허가 공식결정 — 관할기관이 환경허가와 건축·보완설계 적합성을 확인해 수수료 납부 후 건축허가(licença de construção)를 발급하거나 보완·거부를 통지한다. / 산출물: 건축허가·승인도서 또는 거부통지

비공식 한국어 요약이며 법률자문이나 관할기관의 유권해석을 대신하지 않는다.

자료의 현행·운영 상태는 사이트가 자료별 상태·확인일·판단근거로 관리한다. 최신 개정 추적이 끝나지 않은 자료만 검증 예외로 별도 표시한다.

건폐율·용적률·높이·이격·주차, 환경평가 유형, 수수료·실제 기간과 현지 업체 비용은 필지·시설·관할에 따라 달라 확인 전 수치로 사용하지 않는다.

원문 링크 연결 — 공식 자료와 제도의 연결 수준을 뜻하며 자료의 현행·운영 상태는 위 원문 대장의 상태와 확인일로, 개별 사업 적용판정은 ODA 적용 확인사항으로 따로 관리합니다.

국가별 조달·ODA 건축 법제의 기준일 현재 참고자료입니다. 법률 자문이나 해당국 정부·KOICA의 공식 해석이 아닙니다.
자료별 현행·운영 상태는 표시된 확인일과 판단근거로 사이트가 관리합니다. 실제 사업에서는 기준일 이후 변경사항과 해당 공고·대상지에 대한 관할기관의 최종 적용판정을 확인해야 합니다.
