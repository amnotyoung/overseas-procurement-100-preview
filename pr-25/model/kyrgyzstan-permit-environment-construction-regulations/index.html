국가별 건축 인허가 절차 · 12단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · 환경전문심사법·결의 제248호 공식서비스의 환경영향평가서(OVOS)·위원회·결론과 명령 제93-нпа호(Order 93-нпа) 제77~112항의 건축·총괄배치 협의, 전문심사·보완·긍정·부정 결론이다.

  1. B01 환경영향·국가전문심사 적용분류 — 환경부가 건설·재건축·확장 등 사업의 예상 환경영향과 결의 248호 대상범위를 대조해 OVOS 및 국가환경전문심사 적용·관할을 확정한다. / 산출물: 환경영향평가서·국가환경전문심사 적용결론
  2. B02 환경영향평가서·환경설계·관계승인 자료 작성 — 환경전문가가 사업·입지·대안·영향·저감과 모니터링을 담은 단계별 OVOS, 설계 환경부문, 관계기관 긍정의견과 필요시 공공환경심사 자료를 작성한다. / 산출물: 환경영향평가서·환경설계·관계승인 자료
  3. B03 국가환경전문심사 신청·자료제출 — 신청인이 결의 248호 신청서와 프로젝트·OVOS·관계승인 자료를 환경부 국가환경전문심사국에 제출한다. / 산출물: 환경전문심사 접수·자료목록
  4. B04 전문가위원회 구성·환경기술심사 — 환경부가 사건별 전문가위원회를 구성해 OVOS 완전성, 입지·기술대안, 배출·폐기물·수자원·생태·주민보호 및 관계승인을 심사한다. / 산출물: 전문가위원회 심사의견·보완목록
  5. B05 환경영향평가서·환경설계 보완·재제출 — 심사자료가 불완전하거나 환경요건을 충족하지 못하면 신청인과 환경전문가가 조사·대안·저감·관계승인을 보완해 재심사를 신청한다. / 산출물: 수정 환경영향평가서·보완답변·재접수
  6. B06 긍정·부정 국가환경전문심사 결론 — 환경부가 전문가위원회 결과로 긍정 또는 부정 국가환경전문심사 결론을 발급한다. 영향사업은 긍정결론 없이는 후속 승인·시행할 수 없다. / 산출물: 국가환경전문심사 긍정·부정 결론
  7. B07 GZ 기반 건축·구조·설비 프로젝트 작성 — 면허 설계조직이 GZ·기술조건과 긍정 환경결론을 반영해 건축, 총괄배치, 구조, 내부설비와 필요한 소방·환경·산업안전 부문을 작성한다. / 산출물: 협의·전문심사용 프로젝트 도서
  8. B08 10근무일 건축·총괄배치 협의 — 도시계획·건축기관이 건축해법과 총괄배치를 GZ, 건축규범, 유틸리티 기술조건, 문화재·인접지·공공공간 조건에 대조해 최대 10근무일 안에 협의한다. / 산출물: 협의 프로젝트 또는 전항목 사유부 지적
  9. B09 협의 지적 1회 보완·3일 재심사 — 기관이 모든 위반근거를 제시하면 설계자가 프로젝트를 한 차례 보완해 제출하고, 기관은 수정본을 3근무일 안에 재심사한다. / 산출물: 수정 프로젝트·3일 재협의 결과
  10. B10 복합 국가전문심사 신청 — 건축주가 협의된 프로젝트를 건설부 전문심사부서에 제출한다. 기관은 서류완비를 확인하고 필요한 소방·환경·산업안전 심사를 one-stop으로 요청한다. / 산출물: 복합전문심사 접수·분야별 의뢰
  11. B11 15·20·30일 전문심사·보완 — 전문심사기관이 면적별 15·20·30근무일 안에 안전·구조·내부설비와 필요한 전문분야를 심사한다. 지적 시 수정본을 받고 해당 부분을 5·10·15근무일 안에 반복 심사한다. / 산출물: 복합전문심사 의견·수정요구
  12. B12 긍정·조건부·부정 전문심사 결론 — 건설부 전문심사부서가 프로젝트의 규범 적합성을 긍정, 경미한 지적 해소조건부 긍정 또는 구체적 위반을 적은 부정 결론으로 공식 확정한다. / 산출물: 복합 국가전문심사 공식결론
