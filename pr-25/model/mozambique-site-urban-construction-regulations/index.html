국가별 건축 인허가 절차 · 11단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · 민간건축은 관할 지방자치단체(municipality) 또는 지구행정청(district administration)이 처리한다. 사전정보 회신으로 계획도구와 필지조건을 확인한 뒤 건축프로젝트와 보완설계를 순차 승인받는다.

  1. B01 사전계획정보(Informação prévia) 신청 — 신청서 2부, 신축 토지사용수익권(DUAT) 또는 기존건축 권원, 설명서, 위치도, 세금증빙을 제출하고 신축·증축이면 배치·높이·층수·면적·용도를 표시한 추가도면을 낸다. / 산출물: 사전정보 신청서·권원·계획기초도서
  2. B02 접수·도시화부서 회부 — 지방자치단체·지구 사무국(municipal/district secretariat)이 신청을 접수해 도시화·건축 담당부서(urbanisation and construction)로 보내고 필지·계획자료를 대조한다. / 산출물: 접수기록·담당부서 회부
  3. B03 필지 현장방문·계획조건 검토 — 기술부서가 대상지를 방문해 위치·경계·현황을 확인하고 적용 계획수단(planning instruments), 용도·배치·높이·면적 등 건축조건에 대한 기술의견을 작성한다. / 산출물: 현장방문 기록·기술의견
  4. B04 사전계획정보 공식회신 — 관할기관이 적용 계획도구와 건축 요구조건을 행정결정(despacho)으로 확정해 신청인에게 통지한다. / 산출물: 사전계획정보 행정결정·계획조건
  5. B05 건축프로젝트·책임서 작성 — 사전정보 조건에 맞춰 건축프로젝트, 설명서, 토지사용수익권·소유권, 계획·측량도와 설계자 책임확약서(termo de responsabilidade)를 작성한다. / 산출물: 건축프로젝트·설계자 책임서·권원도서
  6. B06 건축프로젝트 기술심사·결정 — 건축사·물리계획가·기술자가 신청의 장애요소와 계획·건축 적합성을 심사하고 건축프로젝트 승인 또는 보완·거부 행정결정을 내린다. / 산출물: 건축프로젝트 승인 행정결정 또는 보완·거부통지
  7. B07 건축프로젝트 보완·재심 — 기술심사 지적에 따라 배치·건축·권원자료를 수정해 관할 기술부서에 재제출한다. / 산출물: 수정 건축프로젝트·보완답변
  8. B08 구조·상하수·설비 보완설계 제출 — 건축프로젝트 승인통지 후 구조안정, 민간 상하수 연결, 적용 전기기계·운송설비 설계와 각 설계자 책임서를 정해진 기간 안에 제출한다. / 산출물: 구조·상하수·설비 보완설계·책임서
  9. B09 보완설계 정합성 심사 — 관할기관이 구조·상하수·설비 설계가 승인 건축프로젝트와 일치하는지 심사하고 불일치·누락이 있으면 보완을 요구한다. / 산출물: 보완설계 적합의견 또는 보완요구
  10. B10 보완설계 수정·재제출 — 구조·상하수·설비 설계의 불일치와 누락을 수정하고 책임서와 함께 다시 제출해 적합성 심사를 받는다. / 산출물: 수정 보완설계·재심기록
  11. B11 건축허가 발급결정·수수료 — 보완설계가 승인 건축프로젝트와 일치하면 관할기관이 프로젝트 승인을 통지하고 법정 수수료 납부 후 건축허가(licença de construção)를 발급하거나 이유를 붙여 거부한다. / 산출물: 건축허가·승인도서·수수료 영수증 또는 거부통지

자료의 현행·운영 상태는 사이트가 자료별 상태·확인일·판단근거로 관리한다. 최신 개정 추적이 끝나지 않은 자료만 검증 예외로 별도 표시한다.

국가별 조달·ODA 건축 법제의 기준일 현재 참고자료입니다. 법률 자문이나 해당국 정부·KOICA의 공식 해석이 아닙니다.
