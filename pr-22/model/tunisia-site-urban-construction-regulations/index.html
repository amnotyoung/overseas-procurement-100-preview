국가별 건축 인허가 절차 · 11단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · 관할 commune 안의 일반 건축사업을 기준으로, 필지 권원과 승인 lotissement·PAU 또는 RGU 조건을 허가도서에 반영해 지방자치단체의 공식 결정을 받는 절차다.

  1. B01 소유권·지적·승인 lotissement 확보 — 신청인이 소유권증명·지적도·필지경계와 해당 필지가 승인된 lotissement에서 나온 토지임을 입증한다. / 산출물: 소유권증명·지적도·승인 lotissement 자료
  2. B02 lotissement·필지 적법성 판정 — 지방 기술부서가 필지의 승인 lotissement 귀속, 경계와 신청인의 권원을 대조하고 미승인 분할이면 건축허가 심사 전 토지정리·분할승인을 요구한다. / 산출물: 필지 적법성 확인 또는 선행 분할승인 요구
  3. B03 PAU 구역·용도 확인 — 관할 commune이 승인 plan d'aménagement urbain(PAU)의 구역·용도와 필지의 계획상 vocation을 특정한다. / 산출물: PAU 구역·허용용도·계획조건
  4. B04 PAU 부재·RGU 적용 여부 판정 — 승인 PAU·상세계획의 적용 여부를 확인하고, 그 밖의 토지는 RGU 적용범위와 자연재해·non-aedificandi 금지구역을 판정한다. / 산출물: RGU 적용조항·건축가능 또는 금지 판정
  5. B05 농지·문화재·자연·보존구역 심사 — 지방 기술부서가 농지, 고고학·역사기념물, 자연·도시경관 및 sauvegarde 구역의 특별 제한과 별도 의견 필요성을 식별한다. / 산출물: 보호구역 제한·관계기관 의견목록
  6. B06 alignment·특별 servitude 승인 확보 — 도로·해양·철도·수리 공공영역 인접 필지는 arrêté d'alignement를, 특별 servitude 인접 필지는 해당 행정승인을 확보한다. / 산출물: alignment 결정·특별 servitude 승인
  7. B07 필지규제 반영 배치·건축도서 작성 — 등록 건축사와 구조전문가가 PAU·RGU·lotissement·servitude의 용도·배치·높이·이격·주차 조건을 평면·배치·단면·입면·구조도서에 반영한다. / 산출물: 도시계획 적합표·배치도·건축·구조도서
  8. B08 지방 기술부서에 완비도서 접수 — 신청인이 권원·도시계획·alignment·servitude·서명도서를 관할 commune 또는 지역기관 기술부서에 제출하고 접수증을 받는다. / 산출물: 건축허가 접수증·완비일
  9. B09 기술심사·현장확인·위원회 의견 — 지방 기술부서가 서류와 현장을 심사하고 건축허가 기술위원회가 PAU·RGU·보호·servitude 적합성에 관한 의견을 확정한다. / 산출물: 기술심사·현장확인 기록·위원회 의견
  10. B10 도시계획 보완·위원회 재심 — 위원회가 지적한 용도·배치·보호·servitude 미비를 수정하고 보완도서를 재제출한다. / 산출물: 수정 도서·보완대응표·재심기록
  11. B11 PAU·RGU 적합 건축허가 결정 — 기술위원회 의견 뒤 commune 의장이 도시계획 조건에 적합하면 arrêté de permis de bâtir를 작성하고, 부적합하면 사유를 적은 거부결정을 통지한다. / 산출물: 건축허가 arrêté 또는 이유부 거부통지

주의

비공식 한국어 요약이며 법률자문이나 관할기관의 유권해석을 대신하지 않는다.

자료의 현행·운영 상태는 사이트가 자료별 상태·확인일·판단근거로 관리한다. 최신 개정 추적이 끝나지 않은 자료만 검증 예외로 별도 표시한다.

건폐율·용적률·높이·이격·주차, 환경평가 유형, 수수료·실제 기간과 현지 업체 비용은 필지·시설·관할에 따라 달라 확인 전 수치로 사용하지 않는다.

원문 링크 연결 — 공식 자료와 제도의 연결 수준을 뜻하며 자료의 현행·운영 상태는 위 원문 대장의 상태와 확인일로, 개별 사업 적용판정은 ODA 적용 확인사항으로 따로 관리합니다.

국가별 조달·ODA 건축 법제의 기준일 현재 참고자료입니다. 법률 자문이나 해당국 정부·KOICA의 공식 해석이 아닙니다.
자료별 현행·운영 상태는 표시된 확인일과 판단근거로 사이트가 관리합니다. 실제 사업에서는 기준일 이후 변경사항과 해당 공고·대상지에 대한 관할기관의 최종 적용판정을 확인해야 합니다.
