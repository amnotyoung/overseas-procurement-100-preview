국가별 건축 인허가 절차 · 13단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · EIA 분류·심사는 장관령 제001/2019호의 전국 절차이고 건축허가는 City of Kigali 또는 대상 District OSC가 BPMIS로 처리한다. Category 4·5는 RHA non-objection이 추가된다.

  1. B01 Project Brief 제출·EIA 등록 — 사업시행자가 사업개요·입지·예상영향을 담은 Project Brief를 환경승인기관에 제출해 EIA 절차를 개시한다. / 산출물: 환경신청 등록·Project Brief
  2. B02 Full·Partial EIA 분류 — 환경승인기관이 장관령 목록과 Project Brief를 대조해 full EIA, partial EIA 또는 목록 밖 경로를 분류한다. / 산출물: EIA 분류·심사경로
  3. B03 EIA 전문가·TOR 확정 — 승인된 EIA 전문가가 제안한 TOR를 환경승인기관이 승인하거나 수정요구하고, 확정 TOR에 따라 평가범위를 정한다. / 산출물: 승인·수정된 EIA Terms of Reference
  4. B04 EIA 조사·이해관계자 의견반영 — 선정 전문가는 확정 TOR에 따라 환경·사회·경제영향과 저감책을 평가하고 모든 관련 이해관계자 의견을 반영한다. / 산출물: EIA Report·관리·저감계획
  5. B05 EIA Report 전자제출 — 선정 전문가는 완료된 EIA Report를 Word·PDF 형식으로 환경승인기관에 제출하고 필요 시 addendum을 첨부한다. / 산출물: 전자 EIA Report·addendum
  6. B06 20일 본심사·추가정보·공중참여 — 환경승인기관이 TOR·지침 적합성을 심사해 20 working days 안에 수락 또는 추가정보를 요구하고, 필요한 경우 15 working days를 더해 공중참여를 실시한다. / 산출물: EIA 심사의견·추가정보 요구·공중참여 기록
  7. B07 환경 추가정보·Addendum 재제출 — 공식 추가정보 요구와 공중참여 의견을 반영해 수정 EIA Report 또는 addendum을 제출한다. / 산출물: 수정 EIA Report·추가정보
  8. B08 환경승인·EIA Certificate 결정 — 환경승인기관이 검토완료 후 프로젝트를 조건부 또는 무조건 승인하거나 거부하고 승인 시 EIA Certificate of Authorization을 발급한다. / 산출물: EIA Certificate·조건 또는 거부결정
  9. B09 BPMIS 건축허가 신청 — 해당 EIA Certificate·환경조건과 전문가 서명 건축·구조·설비도서를 BPMIS로 City of Kigali 또는 District OSC에 제출한다. / 산출물: BPMIS 건축허가 신청번호
  10. B10 완비확인·기술평가 — OSC가 신청완비를 확인한 뒤 planning·architecture·structure·services와 환경조건을 기술평가한다. / 산출물: 완비확인·분야별 기술검토 의견
  11. B11 BPMIS 수정도서 재제출 — OSC·RHA가 전자반려한 분야별 의견과 환경조건을 반영해 수정 건축도서를 BPMIS에 다시 제출한다. / 산출물: 수정도서·BPMIS 재제출 기록
  12. B12 Category 4·5 RHA non-objection — Category 4·5는 RHA가 모든 요구사항의 준수를 심사해 non-objection을 내야 District·City가 유효한 건축허가를 발급할 수 있다. / 산출물: RHA non-objection 또는 보완·부적합의견
  13. B13 건축허가 공식결정 — OSC가 완비일로부터 30일 안에 건축허가를 승인·조건부 승인, amendments 반환 또는 거부하고 지연 시 사유를 서면통지한다. / 산출물: BPMIS 건축허가·조건 또는 반려·거부통지
