국가별 건축 인허가 절차 · 15단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청·심사·보완·결정 절차를 표시한다. 업무구조도와 노드 상세에는 국가 절차만 두고, ODA 조사팀의 사업별 확인질문은 페이지 하단의 별도 접이식 목록으로 분리한다.

적용 범위 · CDA 등록전문가 도서·원스톱 창구(One Window) 건축심사와 Pak-EPA의 초기환경평가·환경영향평가 분류·접수·기술·공중심사·결정을 병렬로 표시한다. 연방 경로를 다른 주에 일반화하지 않는다.

  1. B01 A1·A2 건축·구조 허가도서 작성 — CDA 승인 건축사와 등록 구조기술자가 A1·A2, 건축·구조도면, 안정성확인·계산서와 요구 이의없음확인를 작성·서명한다. / 산출물: 전문가 서명 건축허가 도서
  2. B02 CDA 원스톱 창구 접수·납부고지서(demand note) 납부 — 건축주·대리인이 권원과 서명도서 6세트를 원스톱 창구에 제출하고 부속서 A(Annex-A)에 따라 발급된 납부고지서를 납부한다. / 산출물: 건축허가 접수·신청번호·납부증빙
  3. B03 건축도서 완비성·이의없음확인서 확인 — CDA가 권원·전문서명·도서부수·수수료와 용도별 소방·유틸리티 등 요구 이의없음확인서의 완비성을 확인한다. / 산출물: 완비접수 또는 누락통지
  4. B04 건축·구조·용도 기술심사 — CDA Building Control이 용도지역·배치·BCP 2021·구조안전·접근·화재·관계기관 조건을 심사한다. / 산출물: 건축·구조 기술심사의견
  5. B05 건축도서 공식 보완요구 — 누락·기술불일치가 있으면 CDA가 지적사항과 수정도서·이의없음확인 보완을 공식 통지한다. / 산출물: 건축허가 보완통지
  6. B06 건축도서 보완·재심사 — 등록전문가가 지적사항을 반영한 수정도서·계산·이의없음확인를 재제출하고 CDA가 해당 항목을 다시 심사한다. / 산출물: 보완도서·재접수·재심사 기록
  7. B07 CDA 건축허가 공식결정 — CDA가 계획승인서·승인도서·허가조건을 발급하거나 불허한다. / 산출물: 건축허가결정·승인도서·조건 또는 불허
  8. B08 Pak-EPA 관할·초기환경평가·환경영향평가 분류 — ICT 사업의 위치·유형·규모를 PEPA와 별표 I–II(Schedules I-II)에 대조해 초기환경평가, 환경영향평가 또는 비대상 경로를 판정한다. / 산출물: 관할 EPA·초기환경평가·환경영향평가 분류
  9. B09 초기환경평가·환경영향평가 보고서·신청서 작성 — 환경전문가가 적용 경로의 초기환경평가 또는 환경영향평가, 관리조치와 신청서·수수료 자료를 작성한다. / 산출물: 초기환경평가·환경영향평가 신청자료
  10. B10 초기환경검토·환경영향평가 공식접수·수수료 — 사업자가 Pak-EPA에 적용 보고서·신청서와 수수료를 제출한다. / 산출물: 환경접수·납부증빙
  11. B11 환경 완비성·예비심사 — Pak-EPA가 신청·보고서의 완비성을 심사하고 불충분하면 추가정보·수정을 요구한다. / 산출물: 완비접수 또는 환경보완통지
  12. B12 초기환경검토 기술심사·환경영향평가 공중참여 — Pak-EPA가 초기환경검토를 기술심사하고 환경영향평가이면 공중참여·기술검토를 거쳐 환경결정안을 마련한다. / 산출물: 환경 기술심사·공중참여 기록
  13. B13 환경 추가정보·수정 요구 — 완비성·본심사에서 자료나 완화조치가 부족하면 Pak-EPA가 추가정보·보고서 수정을 통지한다. / 산출물: 환경자료 보완통지
  14. B14 환경자료 보완·재심사 — 환경전문가가 추가정보·수정 보고서를 제출해 Pak-EPA 심사로 회귀한다. / 산출물: 보완 환경보고서·재접수 기록
  15. B15 Pak-EPA 환경 공식결정 — Pak-EPA가 초기환경평가·환경영향평가를 승인·조건부 승인하거나 불승인하며 비대상은 서면 확인한다. / 산출물: 환경승인·조건·비대상 또는 불승인
