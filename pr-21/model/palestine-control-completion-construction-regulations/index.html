공통 ODA 확인업무 · 7단계

아래 7단계는 해당국 법정절차를 복제한 것이 아니라, ODA 사업팀이 수행할 관할확정·현지확인·설계통합·기관협의를 정리한 공통 준비·검증 업무다. 국가별 공식 결정은 별도 Gate 확인대장에서 구분한다.

  1. B15 자격·계약·보험 적용판정 — 현지 설계·시공·검사 주체의 등록자격과 계약상 책임, 의무보험 적용 여부와 견적을 확인한다. / 산출물: 자격·계약·보험 적용표
  2. B16 기술기준·검사계획 확정 — 적용 코드·표준, 착공 전 통지 여부, 법정·계약 검사 Hold Point와 책임자를 확정한다. / 산출물: 적용기준·검사시험계획(ITP)
  3. B17 타설검사·적합증명·점유허가 적용경로 확인 — 공식 법령·서비스에서 착공, 단계검사, 준공·점유의 적용경로와 관할을 확인한다. / 산출물: 검사·준공·점유 법정경로표
  4. B18 시공·시험·품질기록 이행 — 승인도서와 검사계획에 따라 자재·시험·사진·감리·시공 기록을 누적 관리한다. / 산출물: 품질·시험·시공기록 대장
  5. B19 단계검사·변경·재검사 관리 — 법정 또는 계약 검사, 변경승인, 부적합 시정과 재검사 완료를 증빙으로 닫는다. / 산출물: 검사·변경·부적합 종결기록
  6. B20 최종·소방검사·준공·점유결정 — 관할기관과 최종·소방검사를 닫고 as-built·시험성적·인증서를 제출해 준공·점유·사용승인 또는 비대상 회신을 확보한다. / 산출물: 최종·소방검사 결과와 준공·점유·사용승인서·비대상 회신
  7. B21 준공·점유·O&M 인계 Gate — 준공·점유·개장에 필요한 증명과 잔여조건을 확인하고 O&M·보증·자산 인계를 승인한다. / 산출물: 점유·개장 승인 및 O&M 인계팩
