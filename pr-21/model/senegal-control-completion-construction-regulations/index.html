국가별 건축 인허가 절차 · 8단계

해당 국가의 법령·관할기관 공식자료에서 확인한 신청인·전문가·심사기관의 절차를 표시한다. 카드 배지는 노드별 근거 수준이며, ‘현지확인’ 항목은 관할·사업유형에 따라 최종 적용을 다시 확인해야 한다.

  1. B01 보험·기술검사 계약·착공팩 확보 — 의무 적용 여부를 감독기관과 확인한 뒤 인가 기술검사기관의 임무를 계약하고 주체별 건설보험을 가입해 착공 선행조건을 묶는다. / 산출물: 기술검사기관 인가·계약 증빙 · 주체별 보험증권·담보 매트릭스 · 착공 선행조건 체크리스트
  2. B02 지반·구조 비자·굴착 승인 확인 — 의무 적용이 확정된 경우 지반보고서와 구조계산을 인가 검사주체의 비자로 닫고, 굴착 깊이·대상에 따라 필요한 개시허가와 Mines 승인을 확보한다. / 산출물: 지반·구조 검토비자 · 해당 시 굴착 개시허가·Mines 승인
  3. B03 승인도서 시공·품질·HSE·폐기물 기록 — 승인도서에 따라 시공하고 품질시험·기술검사·HSE·폐기물·우연발견 기록과 현장 비치도서를 하나의 추적대장으로 유지한다. / 산출물: 승인도서·변경 이력대장 · 품질시험·기술검사 기록 · HSE·폐기물·우연발견 대장
  4. B04 변경승인·중간검사 — 변경의 허가 영향도를 판정해 중대한 변경은 승인 후 시공하고, 관계기관·기술검사 중간검사의 지적사항을 시정·종결한다. / 산출물: 설계변경 승인서·변경도서 · 중간검사·시정조치 종결기록
  5. B05 준공신고·시험·준공도면 제출 — 승인도서 대비 변경내역, 준공도면, 시험·시운전·기술검사 자료를 정합성 검토한 뒤 준공신고와 함께 제출한다. / 산출물: 준공신고 접수증 · 준공도면·시험·시운전·기술검사 팩
  6. B06 적합검사·적합증명서 발급 — 관할기관의 준공 적합검사에 대응해 지적사항을 닫고 승인도서와의 적합성이 확인된 증명서를 발급받는다. / 산출물: 적합검사 기록·지적사항 종결표 · 적합증명서
  7. B07 ERP 접수검사·공중개방 승인 — ERP 적용이 확정된 경우 안전위원회 접수검사를 신청하고 피난·소방·접근성 지적사항을 종결해 공중개방 승인을 받는다. / 산출물: ERP 안전위원회 접수검사 의사록 · 해당 시 공중개방 승인서
  8. B08 O&M·법정점검·보험 인계 — 설비별 법정점검과 예방정비 주기, 서비스계약, 비상계획, 보증·보험의 담당자와 연간비용을 확정해 운영기관에 인계한다. / 산출물: 설비별 O&M·법정점검 계획 · 서비스계약·보증·보험 인수인계팩 · 연간 운영비·책임표
