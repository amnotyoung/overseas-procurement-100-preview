한 장 캔버스

수원부처와 개발파트너가 국가·부문 우선순위에 맞는 사업을 발굴하고, MIFER 산하 FERD 단일창구를 통해 정부 고위 승인, 양자 협정·MoU·교환각서 협상과 서명, AIMS 등록, 이행 모니터링으로 연결한다.

절차

  1. 수원부처·정부기관과 개발파트너가 국가·부문·지역계획에 맞는 사업수요와 선도기관을 정한다.
  2. 사업개념서와 관련 문서를 FERD 단일창구에 제출하고 주·지역 제안은 해당 최고책임자의 사전승인을 받는다(2020 DAP §6.2, Annex A §10.1).
  3. FERD가 관계부처 의견과 DACU·필요한 고위 승인 절차를 조정한 뒤 승인된 제안을 개발파트너에 공식 전달한다.
  4. 개발파트너의 심사와 함께 수원기관이 설계·예산·조달계획을 구체화하고 FERD가 협정·MoU·교환각서 초안의 법률의견과 협상을 조정한다.
  5. 권한기관 승인과 서명 후 FERD·AIMS에 사업정보를 등록하고 PMU·PSC가 실행·분기보고를 담당한다(2020 DAP §§6.3~6.4, Annex A §§10.2~10.4).
  6. 사업 조달은 재원 제공기관의 별도 규정이 있으면 이를 적용하고, 없으면 제1/2022호와 충돌하지 않는 범위의 제1/2017호를 적용한다(제1/2017호 ¶48(g), 제1/2022호 ¶28).

적용 대상

미얀마 정부기관과 공식 협정·MoU·교환각서로 연결되는 무상·양허성 차관·기술협력 사업의 발굴·승인·실행에 적용한다. 정부 승인 없이 개발파트너가 독립 집행하는 사업은 DAP 정부승인 경로 밖이며, 정부조달은 재원협정의 별도 조달규정 또는 국내 지침을 적용한다.

주의

제1/2022호는 2022-03-17 발령됐고 2022-04-22 관보에 원문이 게재됐다. 별도 유예 시행조항은 없다.

제1/2017호는 전면 폐지가 아니라 제1/2022호와 충돌하는 부분만 후법 우선이다. 보증·평가·기록·이의 규정은 보충 적용되며 2026년 정부신문 입찰도 제1/2017호 조항을 직접 적용한다.

이의신청의 법정 기한·자동 정지효는 공개 지침에 규정되지 않았다는 점까지 확인했으며, 이는 미결 조문이 아니라 현행 규정의 공백으로 기록한다.
